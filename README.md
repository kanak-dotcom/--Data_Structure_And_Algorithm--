

## About
This repository contains solutions, practice code, and notes for the Striver A2Z DSA sheet. The aim is to help with consistent learning, revision, and problem-solving across common computer science topics.

The focus is on:
- Clear and readable implementations
- Understanding the approach behind each solution
- Improving problem-solving consistency
- Building the habit of explaining time and space complexity

## Topics Covered
This repository includes practice and notes for topics such as:
- Arrays
- Strings
- Hashing
- Linked Lists
- Stacks and Queues
- Trees
- Graphs
- Dynamic Programming
- Greedy Algorithms
- Binary Search
- Backtracking
- Sorting and Searching
- Math and Number Theory
